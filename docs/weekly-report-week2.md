## 三、本周完成情况

### 3.1 项目方向与工程框架

本周首先根据《茶饮咖啡小微商户信贷风控项目策划案》重新确认项目定位，将系统统一为面向茶饮咖啡小微商户的经营贷辅助风控原型。系统以商户经营、成本、品牌、合同、舆情和渠道履约等非财务信号为基础，输出可解释风险评分和辅助建议。

已完成以下工程框架：

- FastAPI 后端应用入口及 CORS 配置。
- Vue 3 + Vite 前端项目。
- Element Plus 基础界面组件。
- ECharts 七维风险雷达图。
- Axios 前后端接口调用封装。
- Pydantic 领域模型和接口响应约束。
- 品牌、商户、评分、合同、报告和看板路由。
- 健康检查和 Swagger API 文档。

当前核心业务流程为：

```text
品牌与商户数据
  -> 数据清洗与标准化
  -> 七维风控评分
  -> 合同风险识别
  -> DeepSeek 风险解释
  -> 前端风控看板
  -> 标准化风控报告
```

### 3.4 七维轻量化风控评分

已实现七维规则评分模型：

| 维度 | 权重 | 核心依据 |
| --- | ---: | --- |
| 经营能力 | 22% | 开店时长、月流水、外卖评分、差评关键词 |
| 财务压力 | 22% | 租金、人工、采购和负债占比 |
| 品牌稳定性 | 14% | 加盟成熟度和品牌经营基础 |
| 行业竞争 | 12% | 周边竞品密度和价格竞争压力 |
| 合同风险 | 12% | 合同风险标记和重点条款 |
| 舆情预警 | 10% | 近期品牌或门店负面舆情 |
| 渠道履约 | 8% | 外卖评分和履约质量近似指标 |

评分输出包含：

- 综合风险分。
- 风险等级。
- 七维分项得分和解释。
- 主要风险因子。
- 经营优势。
- 授信辅助建议。
- 贷后关注事项。

风险等级划分：

| 综合分 | 风险等级 |
| ---: | --- |
| 80-100 | 低风险 |
| 65-79.99 | 中低风险 |
| 50-64.99 | 中风险 |
| 0-49.99 | 高风险 |

### 3.5 评分配置化与可解释性

为避免评分规则散落在业务代码中，本周将以下内容迁移到独立 JSON 配置：

- 七维权重。
- 经营能力计算参数。
- 成本和负债扣分参数。
- 品牌稳定性基础分。
- 竞品密度扣分参数。
- 合同和舆情风险分数。
- 风险等级阈值。
- 各等级授信辅助建议。
- 租金、负债和竞品密度风险阈值。
- 开店时长、外卖评分和月流水优势阈值。

新增 Pydantic 配置校验，确保：

1. 七个维度完整且名称正确。
2. 权重合计为 100%。
3. 所有权重大于 0。
4. 风险等级阈值按从高到低排列。
5. 最后一档覆盖最低分 0。

新增接口：

```http
GET /api/risk/config
```

该接口用于展示评分版本、权重、阈值和等级规则，提高系统的可解释性和答辩展示效果。

| 0 | 高风险 |

## 配置校验

`app/core/risk_config.py` 会在加载时检查：

1. 必须恰好包含七个规定维度。
2. 权重合计必须等于 1.0。
3. 每个权重必须大于 0。
4. 风险等级阈值必须从高到低排列。
5. 最后一档必须覆盖最低分 0。

配置不合法时应用会立即报错，避免静默产生错误评分。

## API

新增：

```http
GET /api/risk/config
```

该接口不返回任何密钥或敏感数据，只公开评分版本、维度权重、规则参数、风险等级和阈值，用于系统可解释性展示。

## 项目边界

评分是课程原型中的辅助判断，不是正式金融评分卡。正式业务仍需做样本校准、回测、稳定性监控、公平性评估，并结合征信、流水、工商、司法、纳税和人工审批。
